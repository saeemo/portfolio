# Audit Scope — RetailPro

## Objective
Evaluate whether selected information security controls are designed, implemented, and operating consistently.

## In Scope
- User access management
- Privileged access
- Security awareness
- Vulnerability management
- Backup and recovery
- Incident management
- Supplier security reviews

## Audit Method
- Document review
- Interviews
- Sample testing
- Configuration/evidence review
- Finding validation with control owners
