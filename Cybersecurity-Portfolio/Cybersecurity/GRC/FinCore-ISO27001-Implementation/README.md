# FinCore — ISO/IEC 27001:2022 ISMS Implementation

## Overview
A simulated ISMS implementation for **FinCore**, a fictional financial technology company.

The project demonstrates how ISO/IEC 27001 requirements can be translated into practical ISMS deliverables: scope, asset inventory, risk assessment, risk treatment, Statement of Applicability, policies, and internal audit records.

## Deliverables
- ISMS scope
- Asset inventory
- Risk assessment and risk register
- Statement of Applicability structure
- Risk treatment plan
- Core information security policies
- Internal audit plan, checklist, and corrective action plan

## Reference
ISO/IEC 27001:2022 is the current published edition of the ISMS requirements standard:
https://www.iso.org/standard/27001

> This project is a simulation. It does not reproduce the licensed ISO standard text and is not evidence of certification.
