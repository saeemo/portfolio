# NovaHealth — NCA ECC 2-2024 Compliance Assessment

## Overview
A simulated cybersecurity compliance assessment for **NovaHealth**, a fictional healthcare technology organization in Saudi Arabia.

The project demonstrates a practical assessment workflow aligned to the **NCA Essential Cybersecurity Controls (ECC 2-2024)** without reproducing the official control text.

## Deliverables
- Gap assessment
- Compliance tracker
- Evidence register
- Remediation plan

## Official Reference
National Cybersecurity Authority — Essential Cybersecurity Controls (ECC 2-2024):
https://nca.gov.sa/en/regulatory-documents/controls-list/ecc/

> This is a portfolio simulation. Official NCA documents must be used for any real compliance assessment.
