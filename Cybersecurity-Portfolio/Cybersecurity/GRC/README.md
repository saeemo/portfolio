# GRC Portfolio

This folder contains multiple **simulated GRC engagements**, each using a different fictional company and a different project objective.

| Company | Project |
|---|---|
| SecureTech | Enterprise Risk Assessment |
| FinCore | ISO/IEC 27001:2022 ISMS Implementation |
| NovaHealth | NCA ECC 2-2024 Compliance Assessment |
| RetailPro | Internal Information Security Audit |
| CloudAxis | Third-Party Risk Management |

The projects are designed to demonstrate practical documentation, assessment, governance, risk management, audit, and compliance skills rather than to claim real client engagements.
