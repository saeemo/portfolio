# ISMS Scope — FinCore

## Scope Statement
The simulated ISMS covers FinCore's customer-facing payment platform, supporting cloud services, identity services, employee endpoints, source code repositories, production databases, and the personnel and processes used to operate them.

## Included Locations and Functions
- Headquarters and remote workforce
- Cloud production environment
- IT, Engineering, Security, Finance, and Customer Operations

## Interfaces and Dependencies
- Cloud service providers
- Payment service providers
- Managed SaaS platforms
- External software suppliers

## Exclusions
Any exclusion must be justified and must not affect FinCore's ability to meet the defined security objectives of the simulated ISMS.
