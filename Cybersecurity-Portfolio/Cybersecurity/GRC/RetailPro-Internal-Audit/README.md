# RetailPro — Internal Information Security Audit

## Overview
A simulated internal audit for **RetailPro**, a fictional retail organization.

The project demonstrates audit planning, evidence-based testing, findings management, root-cause analysis, and corrective action tracking.

## Deliverables
- Audit scope
- Audit plan
- Audit checklist
- Findings register
- Corrective action plan

> This project is a simulation created for portfolio demonstration.
