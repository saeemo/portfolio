# CloudAxis — Third-Party Risk Management

## Overview
A simulated third-party cyber-risk assessment program for **CloudAxis**, a fictional cloud services company.

## Objectives
- Inventory suppliers and services.
- Assign vendor criticality.
- Assess cybersecurity risk.
- Track questionnaire responses and evidence.
- Record findings and treatment actions.

## Deliverables
- Vendor inventory
- Vendor risk assessment
- Security questionnaire
- Findings register
- Treatment plan

> This is a simulated portfolio project. Vendor names are fictional.
