# Cybersecurity Portfolio

A structured portfolio of hands-on networking, technical cybersecurity, and GRC work.

## Structure

- **Network** — networking labs and troubleshooting documentation.
- **Cybersecurity / Technical** — hands-on web security and security tooling labs.
- **Cybersecurity / GRC** — simulated governance, risk, compliance, audit, ISO 27001, NCA ECC, and third-party risk projects.

> **Portfolio note:** GRC organizations in this repository are fictional and are used only to demonstrate practical methodology and documentation skills. Technical labs are educational lab environments.
